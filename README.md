# Student Study Planner

## Project Description

Student Study Planner is a Python-based application designed to help students organize their assignments, manage deadlines, and track their study progress.

## Features

* **Add Tasks:** Add assignments with subject names and deadlines.
* **View Tasks:** Display all added assignments.
* **Complete Tasks:** Mark assignments as completed.
* **Delete Tasks:** Remove assignments from the task list.
* **View Schedule:** Check upcoming assignments and deadlines.
* **Track Progress:** View total tasks, completed tasks, pending tasks, and completion percentage.

## Technologies Used

* Python 3
* Visual Studio Code

## Project Files

* `main.py` – Main program and menu system.
* `tasks.py` – Task management functions.
* `schedule.py` – Assignment schedule management.
* `progress.py` – Study progress tracking.
* `README.md` – Project documentation.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run the following command in the terminal:

```bash
python main.py
```

5. Select an option from the menu to manage your assignments.

## Purpose

The purpose of this project is to help students maintain an organized study routine, complete assignments on time, and monitor their academic progress.
